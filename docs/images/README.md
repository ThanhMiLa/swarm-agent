# SwarmAgent images

`swarm-agent.png` is generated by `npm run logo` from the
[editable SVG](../../src/assets/swarm-agent.svg), along with the favicon
and the app and tray icons.

For documentation screenshots, use the current app. Capture a workspace with
Agent Team open at a readable width. Hide personal paths, account details and
terminal content before adding the screenshot to the repository.
